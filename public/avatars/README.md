# Avatar images

Place patient/staff photos here as JPEG files, named using the slugified version of the person's display name:

  "Jordan Rivers"    →  jordan-rivers.jpg
  "Dr. Amelia Cruz"  →  dr-amelia-cruz.jpg
  "Taylor Green"     →  taylor-green.jpg

Rules:
- Lowercase
- Spaces → hyphens
- Remove any characters that aren't a-z, 0-9, or space before slugifying
- Recommended size: 128×128 px minimum, square crop, JPEG

If a file is missing the Avatar component will fall back to the person's initial
on their colour chip automatically — no extra config needed.
